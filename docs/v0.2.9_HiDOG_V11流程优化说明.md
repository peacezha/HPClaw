# HPClaw v0.2.9 HiDOG V11 流程优化

## 优化内容

- 两个 HiDOG 流程均改为调用随包的确定性启动器，不再把长篇流程说明交给 AI 临时拼命令。
- 载体追踪按 V11 的真实依赖运行，移除无效的 BWA、SAMtools、pysam 和线程配置。
- 载体追踪支持 spacer reference / guide manifest 二选一，并开放 V11 的 anchor、barcode、spacer 与样本阈值参数。
- 扩增子流程支持 FASTQ / Hi-TOM 输入选择、常规编辑 / Prime Editing、dual-primer UMI、断点续跑和高级参数。
- 参数组合会在提交前校验，避免输入不完整或模式冲突时消耗集群计算时间。
- 两个流程都自动生成 `qc_summary.json`、`report.md` 和 `report.html`，不再依赖 AI 对大段输出进行临时总结。
- 已完成的 vector-trace 结果可直接复用；扩增子分析沿用 V11 原生 resume 状态，Agent 中断后可从现有结果继续。

## 结果位置

- 载体追踪原始结果：`<RUN>/results/vt_results`
- 扩增子原始结果：`<RUN>/results/hidog_run`
- 自动质控与报告：`<RUN>/results/report`

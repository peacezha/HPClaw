# HPClaw AI 智能化提升方案

## 当前状态分析

观察到的 AI 行为问题：
1. 返回 "HTTP 400" 而非具体错误信息（已部分修复）
2. 中断后恢复连接失败
3. 简单命令（如 `ls`）也等待确认（已改为 trust_all 模式）
4. 不够像"智能体"——缺乏主动建议和推理深度

## 当前系统提示词问题

现有的系统提示词非常精简（仅 7 条铁律 + 格式说明），缺乏以下关键要素：
- **角色人格**：没有定义 AI 的"研究员"角色定位
- **推理深度**：没有要求 AI 展示分析思路和备选方案
- **主动建议**：没有指示 AI 在任务完成后主动给出分析建议
- **文件感知**：集群当前目录的文件列表未注入上下文
- **技能匹配**：生信技能知识库未根据当前文件类型自动推荐

## 具体改进建议

### 1. 增强系统提示词（立即见效）

在 `AIChat.tsx` 的 `handleAgentMode` 函数中，将系统提示词扩展为包含：

```
你是 HPClaw 生物信息学智能助手，一位经验丰富的生信研究员。
你不仅执行命令，更要像科研伙伴一样思考。

【分析深度要求】：
- 每个 <thought> 必须包含：当前观察到的现象 → 你的分析判断 → 下一步的理由
- 遇到错误时，分析错误原因并给出 2-3 种可能的解决方案
- 看到文件时，根据文件名、大小、格式推断实验目的和分析方向

【主动建议】：
- 任务完成后，除了汇报结果，还要给出 1-2 条后续分析建议
- 发现数据特征时（如样本量、质量指标），主动指出值得关注的点
- 推荐相关的下游分析方法和生物信息学工具
```

### 2. 注入文件感知上下文（中等改动）

当前集群状态采集只获取 `bjobs` 和 `quota`，没有注入当前目录文件列表。在 Agent 启动时自动采集：

```typescript
// 在 clusterState 中增加文件列表
const fileList = await executeCommand('ls -lh | head -30', true);
clusterState += `\n【当前目录文件】:\n${fileList}`;
```

这样 AI 在思考时就能看到目录中的文件，无需先执行 `ls`。

### 3. 文件类型驱动的技能匹配（中等改动）

根据 `fileRecognizer.ts` 识别当前目录文件类型，自动匹配相关技能：

- 检测到 `.vcf.gz` → 自动加载变异检测/注释技能
- 检测到 `*_R1.fastq.gz` → 自动加载 RNA-seq/QC 技能
- 检测到 `.bam` → 自动加载比对/变异检测技能

### 4. 增强错误恢复能力（小改动）

在 Agent 循环中，当命令返回非零退出码时：

```typescript
if (output.includes('command not found')) {
  contextMsgs.push({ role: 'user', content: '[系统提示：命令未找到。建议先执行 mii search 或 module av 确认可用工具]' });
}
```

### 5. 记忆持久化增强（中等改动）

当前对话记忆在中断后可能丢失。改进：
- 每次 Agent 步骤完成后立即持久化 `structuredMemory` 到 localStorage
- 中断恢复时加载上次的记忆状态
- 添加 `[恢复上次任务]` 按钮

### 6. Token 预算优化（小改动）

对生信任务常见的超长输出（如 BLAST 结果、VCF 文件内容）自动截断并摘要：

```typescript
if (output.length > 5000) {
  const summary = `输出共 ${output.length} 字符。前 2000 字符: ${output.slice(0, 2000)}...[已截断]`;
  // 自动统计关键信息（如变异数量、比对率等）
}
```

## 优先级排序

| 优先级 | 改动 | 效果 | 工作量 |
|--------|------|------|--------|
| P0 | 增强系统提示词 | 立竿见影提升智能感 | 10 分钟 |
| P1 | 注入文件感知上下文 | AI 少执行一次 ls | 5 分钟 |
| P1 | 增强错误恢复 | 减少中断后失败 | 15 分钟 |
| P2 | 文件类型驱动技能匹配 | 更精准的工具推荐 | 1 小时 |
| P2 | 记忆持久化增强 | 中断后可恢复 | 2 小时 |
| P3 | Token 预算优化 | 处理大数据输出 | 1 小时 |

## 建议先实施 P0+P1

只需修改 `AIChat.tsx` 中的 `handleAgentMode` 函数：
1. 扩展系统提示词，增加角色定义、推理深度、主动建议要求
2. 在 clusterState 采集时增加 `ls -lh` 输出
3. 在 catch 块中增加智能错误恢复提示

这三项改动总计约 30 分钟，但能显著提升 AI 的智能感知和实用性。

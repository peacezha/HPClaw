# 文件传输工作区

## 打开与关闭

在应用右侧边缘有一个文件夹图标按钮（文件传输启动器）。点击该按钮即可打开文件传输工作区覆盖层。若当前有正在进行的传输任务，按钮上会显示任务数量角标和进度条。

点击工作区右上角的关闭按钮或按 `Escape` 键可关闭工作区。工作区支持最大化模式，点击最大化按钮可展开至全屏。

## 添加与信任主机

文件传输工作区在桌面应用模式下支持保存主机配置。

- 打开工作区后，未连接状态下会显示**主机配置**面板
- 点击已保存的主机配置即可发起连接
- 首次连接时，系统会验证远程主机指纹：
  - 若指纹未知，弹出指纹确认提示，用户需手动信任
  - 若指纹与已保存记录不匹配，连接将被拒绝
- 信任的指纹会持久化保存，后续连接自动校验

主机配置通过 Electron `safeStorage` API 加密存储，密码和 TOTP Secret 不会以明文形式出现在配置列表中。

## 浏览本地与远程文件

连接后，工作区显示左右双面板：

- **左侧面板** — 本地文件浏览（通过 Electron 桌面 API）
- **右侧面板** — 远程文件浏览（通过 SFTP 协议）

每个面板显示文件列表，包含文件名、大小、修改日期和权限。支持：
- 单击选中；双击目录进入目录
- 双击本地文件通过系统默认软件打开
- 双击远程文件先下载到受管缓存，再通过系统默认软件打开并自动回传修改
- 按名称、大小、日期排序
- 右键上下文菜单：新建文件夹、重命名、复制、粘贴、复制路径、打开并编辑、预览、删除
- 返回上级目录（..）

## 上传、下载、暂停与恢复

文件传输通过拖放或上下文菜单触发：

- **拖放上传** — 将本地文件拖到远程面板
- **拖放下载** — 将远程文件拖到本地面板
- 右键菜单也支持发起传输

文件传输队列显示在面板底部，包含：
- 传输进度条和速率显示
- 暂停/恢复按钮 — 暂停的传输可稍后恢复
- 取消按钮 — 终止传输
- 重试按钮 — 对失败的传输重新尝试
- 清除已完成 — 清理已完成或已取消的记录

已完成的传输（包括暂停的传输）在断开连接后不会丢失，队列状态会持久化保存，重新连接后可继续。

## 解决冲突

当目标文件已存在时，弹出**文件冲突**对话框，显示源文件、目标文件、已有文件大小和修改时间。用户可选择以下策略：

- **覆盖** — 用源文件替换目标文件
- **跳过** — 保留目标文件，不做任何操作
- **重命名** — 为目标文件生成新名称后保存
- **续传** — 从断点继续传输（仅适用于部分完成的传输）

## 验证传输

传输完成后，系统默认按文件大小进行校验。支持两种验证模式：

- **大小验证（默认）** — 比较源文件和目标文件的大小
- **SHA-256 验证** — 计算文件哈希值进行完整性校验，安全性更高但速度较慢

可在传输设置中配置验证模式。

## 搜索与预览

工具栏提供搜索和同步按钮。

**搜索面板：**
- 支持对当前目录递归搜索文件
- 输入关键词后自动进行去抖搜索（300ms 延迟）
- 显示搜索结果列表，最多 5000 条
- 点击结果可导航到对应目录

**文件预览：**
- 右键“预览”采用应用内只读模式，不会修改或回传文件
- 支持图片、PDF、DOCX、XLS/XLSX、CSV/TSV、Markdown、代码、日志和常见生物信息文本
- 100 MiB 及以上的 FA/FASTA/FASTQ、日志等行式文本仅显示 `head -20`
- 二进制文档按类型设置安全上限，超限时可改用“打开并编辑”
- 预览对话框显示文件路径、来源、大小和修改时间

## 使用系统默认软件编辑远程文件

双击远程文件或右键选择“打开并编辑”后，HPClaw 会：

- 先显示“正在打开”，仅在 Windows 确认默认软件已接收打开请求后切换为“编辑中”；打开失败可直接重试

1. 在应用数据目录中创建独立的受管缓存副本
2. 通过现有传输队列完整下载文件，并显示下载进度
3. 调用 Windows 对该扩展名设置的默认软件打开缓存副本
4. 监听保存操作；文件稳定后自动上传到原远程路径
5. 默认软件关闭时再次比较文件指纹，确保最后一次保存已同步

自动上传采用直接覆盖策略，并通过远程临时文件和原子重命名避免出现半个文件。如果上传失败，本地缓存会一直保留，文件工作区顶部会显示失败会话，并提供“重试上传”和“打开本地副本”。

如果编辑期间再次保存，HPClaw 会按文件指纹去重；正在上传的版本完成后若检测到更新版本，会继续上传最新版本。

应用重启后会恢复仍有本地缓存的失败编辑会话。关闭 HPClaw 时若还有未同步文件，系统会提示未同步数量；即使选择强制关闭，也不会删除恢复副本。

## 修改远程权限

在远程文件面板中，可通过上下文菜单修改文件或目录的权限。支持八进制权限码输入（如 `644`、`755`），同时也提供 owner/group/other 的读、写、执行复选框可视化编辑。

## 对比与同步目录

**同步规划器**提供目录对比功能：

1. 点击工具栏「同步」按钮打开同步规划器
2. 系统对比本地和远程目录的文件列表
3. 生成同步计划，分类显示：
   - **上传** — 本地有但远程没有的文件
   - **下载** — 远程有但本地没有的文件
   - **冲突** — 两边都有但内容不同的文件
   - **跳过** — 两边一致的文件
   - **删除** — 目标目录中多余的文件（需勾选「删除多余文件」）
4. 若计划包含删除操作，会弹出二次确认对话框
5. 确认后，所有同步操作转为传输任务加入队列

这是一个预演（dry-run）过程，在实际执行前会显示完整操作列表供用户审查。

## 断开连接后恢复

- 连接断开时，正在进行的传输会自动暂停
- 传输队列状态持久化保存在本地，不会因断开而丢失
- 重新连接后，可手动恢复暂停的传输
- 支持自动重连机制，当检测到连接中断时会尝试恢复会话

## 凭据与主机密钥安全

- **加密存储** — 密码和 TOTP Secret 通过 Electron `safeStorage` API 加密后保存
- **TOTP 自动生成** — 保存了 TOTP Secret 的主机在连接时自动生成动态验证码，无需手动输入
- **指纹认证** — 主机密钥指纹经用户确认后保存，后续连接自动校验
- **最小暴露** — 配置列表仅返回元数据（是否有保存的密码/TOTP），不返回实际凭据

## 故障排除

**会话超时**
- 远程连接长时间无操作后可能断开
- 重新通过工作区主机列表发起连接

**指纹不匹配**
- 若远程主机重新安装或更换了 SSH 服务，指纹会变化
- 需要在主机配置中重新信任新指纹

**权限不足**
- 文件上传/下载时需要目标目录的读写权限
- 检查远程目录权限，必要时使用 `chmod` 修改

**传输失败**
- 检查网络连接和 SSH 会话状态
- 查看传输队列中的错误信息
- 使用重试功能重新尝试失败的传输
- 大文件传输建议启用续传功能

**搜索无结果**
- 确认搜索路径正确
- 搜索支持文件名匹配，不支持全文内容搜索
- 结果超过 5000 条时仅显示前 5000 条

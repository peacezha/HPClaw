# Windows v0.4.49 本地版本

本次仅生成 Windows x64 安装包。不推送 GitHub、不创建 Release、不发布在线更新；不替换用户当前打开的软件或操作真实集群。

## 流程库管理

- 左侧流程列表及管理页均新增「正式流程 / 待弃置」板块，支持中英文界面。
- 待弃置项显示移入原因，以及仍存在且可用的替代流程。定义仍保留，可以编辑、恢复或删除；恢复决定跨重启保留，不会自动再移走。
- 待弃置项不参与 AI 推荐，不能创建新 RUN；既有运行记录、远程文件和调度器作业不受移动操作影响。
- 内置、用户创建、AI 生成及待弃置流程均提供删除入口。使用应用内确认框，默认聚焦取消，显示准确影响范围；失败保留确认框并显示错误，防止双击重复提交。
- 删除仅移除定义，不删除集群数据、RUN 目录、结果、报告或会话，不发送 bkill 等命令。删除前在运行时数据目录的 `workflows/deleted-definitions/` 留存定义 JSON 备份。此备份需要人工恢复，不是界面回收站。
- 删除内置流程会登记种子屏蔽记录，后续启动和种子更新不再自动重新加入。
- 串行化流程库读写，避免并发移动、恢复和删除互相覆盖。

## 自动移入规则

只处理有明确证据的情况，不按相似名称或分析领域判断质量。

1. 未修改的四个独立英文展示版本：DAP-seq、TF ChIP-seq、Histone ChIP-seq 和 ATAC-seq。主流程已支持中英文显示；独立英文模板保留在待弃置中供恢复，命令和英文报告资产不重写。
2. 实验性 TF ChIP-seq DAG：与线性模板重叠，独立随机子采样的伪重复实现尚未验证，不应直接当作正式可复现模板。
3. 文献审计 `readiness=insufficient` 的定义，或必需步骤仅有 `REVIEW_REQUIRED` 注释、没有可执行命令的定义。
4. 执行定义完全相同的重复项，保留优先级更高的定义，另一项收起；不把不同分析路线合并。
5. 已停止维护的旧系统种子，改为留存待核对而非自动删除。

已有明确生命周期标记的流程尊重用户决定；单纯缺输入的模板不自动判为低质量。保留正式流程不等于已经逐一完成科学正确性认证。

2026-10-10 对当前用户库做只读内存模拟：75 项中预计 8 项待弃置、67 项正式（4 个语言变体、1 个 DAG、3 个文献草稿）。未写入实际运行时数据；安装新版后才由新版本迁移。

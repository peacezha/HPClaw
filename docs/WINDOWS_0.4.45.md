# HPClaw v0.4.45 — Windows 修复说明

本次只构建 Windows x64 安装包，保留经典界面；不修改正在运行的集群作业、用户配置或历史对话。Mac 和 Linux 网页版本不随本次更新。

## 集群 HTML 报告预览

- 修复 `07_report/report.html` 等相对路径触发 `remote path must be absolute` 的问题。预览根据该条消息之前的项目目录、明确的输出/工作目录和流程 RUN 目录，逐个核实文件是否存在，再读取绝对路径。
- 不递归搜索集群，不用其他会话的目录。同名候选报告有多个时必须明确选择；无法定位时可填写集群绝对路径。权限或会话错误不会被误判为“本地报告”。
- HTML 正文、相对 CSS、JavaScript 和图片通过已有隔离流式接口读取；流程运行面板与聊天预览使用同一个组件，不再通过通用文本预览下载整份 HTML 后显示。
- 不同项目的同名相对报告不会复用错误的侧栏标签。原先从 `07_report/report.html` 错提取 `/report.html` 的下载链接也已修正。
- 保留脚本隔离与默认禁止外部网络资源的安全策略。需要 CDN 的报告仍需用户明确允许外部资源；不支持的外部页面嵌入限制不由本次修复绕过。

## 专业英文流程界面

- 补齐 59 条内置流程的名称、说明、关键词、步骤、参数标签/帮助、参考数据提示、质控标准和流程图标签。审计覆盖 804 条含中文的元数据短语。
- 编辑器也按当前语言展示内置流程；切换语言后不编辑直接保存，仍保存原有命令、参数值和元数据，不静默覆盖科研内容。
- 翻译使用经过审阅的生物信息和计算机术语表，并保留工具名、版本、阈值、选项、路径和标识符。不自动翻译用户自定义流程正文、文献证据、历史 AI 回答或脚本注释；这些是研究内容，不是软件界面。
- 保留 v0.4.44 的安装时中英文选择、应用内语言切换及偏好保存。既有用户已保存的语言优先，不因重新安装而重置。

## 验证范围

回归测试覆盖路径候选、同名报告、权限错误、流式大报告、相对资源和语言切换后的原始内容保存。界面检查使用真实界面组件与报告接口、隔离的 SFTP 演示文件，不代表已登录用户集群验证当前报告。安装包另做编译、压缩完整性、打包后后端启动与更新清单校验。

安装前正常关闭 HPClaw，再运行 `HPClaw-Setup-0.4.45-x64.exe`。升级不要求删除应用数据。若报告仍无法定位，可在预览错误面板直接填写实际集群绝对路径；不要用 Windows 本地路径代替集群路径。

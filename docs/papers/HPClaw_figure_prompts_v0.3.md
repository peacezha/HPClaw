请绘制一张适合计算生物学软件论文的系统架构图，白底、黑灰文字、少量蓝绿色强调色、无渐变、无装饰性图标。左侧为用户请求和 Web/Electron 工作台，中部依次为 SSH 会话层、集群状态快照、文件识别器、技能索引与技能图谱、结构化记忆和观测存储，右侧为 AI Agent 工具循环、LSF 作业提交、远程文件和结果预览。用实线箭头表示请求、状态和工具结果，用虚线表示记忆与观测回写。清楚标出 `run_command`、`search_skills`、`ask_user`、`save_skill`、`bsub`、`bjobs`。图中不放性能数字，不把 Agent 画成拟人化机器人。

建议图注：图 1 | HPClaw 的系统架构。用户请求通过统一工作台进入 Agent，Agent 读取远程集群状态和任务相关技能后调用受控工具；命令、作业、文件和用户确认结果回到同一会话，并写入观测与结构化记忆。

请绘制一张环形流程图：用户任务、环境探查、技能检索、参数判断、风险判断、生成单条命令或 LSF 脚本、SSH/LSF 执行、返回结果、更新观测与记忆。使用两个菱形节点表示“关键参数是否完整”和“操作是否需要确认”。缺少参数或需要确认时进入 `ask_user`，用户确认后返回流程；命令失败、重复或超过预算时进入停止状态。右侧列出当前实现的工程约束：最多 50 个 Agent step、最多 40 次 `run_command`、连续 3 次失败停止、同一命令第 3 次重复停止、直接 `rm` 拒绝、长任务使用 `bsub`。用橙色表示确认和停止路径，绿色表示正常执行路径，灰色表示状态记录。

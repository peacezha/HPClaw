# HPClaw v0.4.41

## 恢复 0.4.39 界面

- 主工作台、侧栏、欢迎页、配置表单和全局样式恢复为 v0.4.39 的布局与视觉代码。
- 恢复横排四列导航、简洁品牌、居中欢迎页、紧凑任务入口及原来的文字尺寸、留白和配色；移除 v0.4.40 的新导航与大标题设计。
- HTML 报告卡片恢复紧凑外观，网页侧栏默认恢复 600px 宽度。仍可手动调整报告大小和全屏查看。

## 保留功能修复

这次只回退界面，不把软件功能降级：

- 保留 v0.4.39 / v0.4.40 的 Agent 进度识别、续跑、作业提交幂等、DSH 工具契约和对话存档修复。
- 保留集群与本地 HTML 报告流式读取、相对路径资源加载、隔离沙箱及外部资源开关。
- 保留专业术语与文件名保护，避免任意子字符串翻译。
- 保留中英文 ChIP-seq、DAP-seq、ATAC-seq 质控、TSS / SPOT、基因 BED 支持和文献复现清单改进。

## 安装与在线更新

Windows x64：下载 `HPClaw-Setup-0.4.41-x64.exe`，或在软件更新中心检查更新。
Release 同时包含 `latest.yml` 和 `.blockmap`，版本号提高到 0.4.41，以便从 0.4.40 正常在线更新。

更新前保存当前对话，在方便时关闭 HPClaw。集群批处理作业不会因桌面应用关闭而自动取消，但自动续跑需要应用重新连接。

## 验证

四个主界面文件与 v0.4.39 一致。TypeScript 检查通过；181 个测试文件、1443 项测试全部通过；前端与 Electron 服务构建及安装包 CRC 校验通过。另检查包内版本、经典界面资源和报告流式接口，并在发布时校验更新清单。

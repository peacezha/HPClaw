# TRACE v0.4.54 · Windows

本次发布 Windows x64 安装包及自动更新文件。macOS 和 Linux 网页端本次没有新版产物。

## 修复与调整

- 将 BioSkills「ATAC-seq 染色质可及性全流程」和「ChIP-seq 分析全流程」保留为正式流程，不带待弃置标签。
- 删除 BioSkills「Hi-C 三维基因组分析全流程」「CLIP-seq RNA 结合位点全流程」「因果基因组学全流程」「CRISPR 编辑设计与验证全流程」，并在新版本首次启动时清理现有待弃置定义。独立的 ENCODE Hi-C/eCLIP 流程保留。
- 删除前备份流程定义，登记系统流程删除记录，避免重启后重新出现。不会删除集群 RUN 目录、分析数据或运行结果；以后新建的待核对草稿不会被反复自动清理。
- 修复「数据怎么准备」整个板块的中英文切换，包括格式说明、模板标签、JSON 说明和 AI 协助按钮。文件路径、样本值、TSV 列名和科学命令不会被翻译。
- 修复普通文本编辑的 Ctrl+C/Ctrl+V，以及文件面板抢占全窗口快捷键的问题。终端无选区时 Ctrl+C 仍用于中断命令；终端粘贴不重复发送。
- 复制按钮优先使用桌面剪贴板通道，兼容浏览器复制回退；模板或代码复制失败时不再显示虚假的成功提示。
- 软件名称统一为 TRACE，保留旧版 HPClaw 的已有对话、集群配置和数据目录兼容性。

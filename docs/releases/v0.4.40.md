# HPClaw v0.4.40

## Agent 执行与存档

- 修复 DSH 的 `call_web_api` 工具缺少输出契约导致引擎启动失败、回退旧引擎的问题。
- 包含 v0.4.39 的进度停滞识别、作业提交幂等和作业完成后续跑改进，不再仅用固定三次续跑判断失败。
- 对话存档文件确实不存在时，可由完整消息快照恢复同一对话 ID；权限或连接失败不会被当作文件不存在。

## HTML 科研报告

- 对话、侧边报告和文件预览使用专用 HTML 流式读取，报告展示不再受普通卡片 10 MiB 上限或大文本 head 截断影响。
- 支持读取报告同目录及子目录中的图片、CSS、JavaScript、字体和数据；保持报告所属集群会话，不随活动集群切换。
- 预览仍使用隔离沙箱。外部网络资源默认禁止，可由用户按报告需要开启；同目录资源只读，不允许词法路径越界。
- 报告面板支持拖动调宽、全屏和内联卡片高度调整。极大报告仍受电脑内存与浏览器能力影响。

## 界面与翻译

- 新增可折叠导航、常驻任务执行位置、侧栏语言切换与版本号；调整导航层级、留白、初次配置和任务入口。
- 增加窄窗口布局、移动式导航遮罩及减少动态效果设置支持。
- 取消任意子字符串翻译，只翻译登记的界面文案与明确模板，保留 OpenAI、ChatGPT、文件名和生物信息术语。

## 生物信息流程（包含先前更新）

- ChIP-seq、DAP-seq、ATAC-seq 中英文流程含 SPOT 与 TSS 曲线，默认不使用 blacklist；质控失败如实标注，不直接归因为测序深度。
- TSS 邻域富集与基因区域 scale-regions 曲线区分命名；支持用户提供基因 BED，或从注释构建，记录参考注释来源。
- 文献学习提取数据登录号、原始文件、关键参数、软件版本及缺失信息，生成可核查的复现清单。

## 安装与在线更新

Windows x64：下载 `HPClaw-Setup-0.4.40-x64.exe`。Release 同时提供 `latest.yml` 和 `.blockmap`，供现有安装的更新中心使用。
安装更新前保存当前对话，待方便时关闭 HPClaw；集群批处理作业不因桌面应用关闭而自动取消，但自动续跑需应用重新连接。

## 验证

发布前运行 TypeScript 检查、全量回归测试、前端与 Electron 服务构建，以及安装包 CRC 和更新清单校验。未在用户集群上重新执行完整生物信息分析，也不宣称界面已经通过奖项评审。

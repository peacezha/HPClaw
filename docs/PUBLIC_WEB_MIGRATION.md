# 面向大众的集群网页端：改版范围与验收

状态：公共网页隔离实现与验收；部署方式见 [PUBLIC_WEB_DEPLOYMENT.md](PUBLIC_WEB_DEPLOYMENT.md)，发布结果以 GitHub 工作流和 Release 新资产为准。
现有 v0.4.41 Linux 网页包仍是单用户服务，不能移除统一口令后直接公开。
本改版只针对网页端，不删除 Windows / Mac 桌面的本地工作台。

## 用户已明确的需求

- 网页端不提供部署服务器的“本地工作台”“本地文件”“本地执行”。
- 用户通过自己的集群账号登录；不得共用一个集群账号来隔离不同访客。
- 对话、记忆、私人流程、任务恢复信息等持久用户数据保存在对应集群账号的用户目录，不能落到网页服务器的共享用户库。
- 复用已有网页部署环境，提供简单部署、启动、升级命令；部署不能覆盖其他网站、私自安装系统软件或改变防火墙。
- 平台后台的临时处理和受控缓存不属于用户可操作的“本地工作区”。临时数据需要逐用户隔离、明确生命周期和清理策略；不能以“缓存”为由永久保存用户对话或密钥。

## 已确认的现有边界

- `ClusterConversationStore` 已支持远程 `~/hpclaw_conversations/`，集群对话读写可以沿用。
- `server.ts` 的 SSH 会话表是进程全局状态；会话解析只验证 ID 存在，未验证其属于当前浏览器用户。
- 当前不指定目标的退出操作关闭所有 SSH 会话，不能作为公共服务行为。
- AI 配置、私人流程、文献学习草稿、部分任务恢复信息使用网页服务器的共享数据路径。
- 本地文件路由、DSH 工作区和本地 Agent 不可仅在界面隐藏，公共网页后端也必须禁用或改为集群工具。
- WebSocket、SSE、文件 / HTML 资源、重连、取消和任务续跑都属于同一用户授权边界。

## 实现要求

1. 静态页面和集群登录页可公开；集群 SSH 认证成功后建立独立、安全的网页会话。移除面向访客的统一 HTTP Basic 口令不能移除应用授权。
2. HTTP / WebSocket 请求同时验证网页用户身份与集群会话归属；拒绝访问、操作或取消其他访客的会话与任务。退出只作用于本人。
3. 集群未连接或保存失败时明确告知用户，禁止静默写入部署服务器共享库。跨设备登录同一集群账号可恢复已保存的对话、任务上下文和私人流程。
4. SSH 密码只用于认证 / 当前连接所必需的内存状态，不写入浏览器持久存储或服务日志；断开与过期时释放。主机指纹校验保留。
5. 私人用户设置与平台公共资源分开。内置流程 / 技能可只读共享；用户自定义内容与 AI 凭据不可跨用户复用。
6. 公网全程 HTTPS，限制登录尝试、并发和空闲生命周期；校验可连接集群与外部 API 目的地址，不能把网页后台变成访问本机 / 内网的任意代理。
7. 复用旧网站前确认运行服务和反向代理设置，支持 WebSocket 升级、SSE 流式输出及独立路径 / 域名。不会把有后端的集群门户当作纯静态网页发布。

## 已确认与部署现场待验收信息

- 原网页的访问地址、部署方式或脱敏部署脚本 / 反向代理配置；不要提供密码、私钥或 API 密钥。
- 已确认：npm 部署，每位用户自带 API Key，可填写自己的集群地址；无需统一网站密码。
- 如服务需要连接指定的内网集群，请提供允许的主机 / 端口清单；未确认前不放开内网和本机访问。

## 发布验收

- 两位独立访客同时登录不同集群 / 账号，终端、对话、流程、模型配置和任务互不影响。
- 请求中篡改目标会话、对话、任务或资源标识不能访问其他用户数据；HTTP、WebSocket、SSE 一并覆盖。
- 任一用户退出、断线、取消任务或删除对话不影响另一位用户。
- 集群断开、网页重启、存储失败均不会回退到服务器本地库；重新登录后从集群恢复持久信息。
- 本地读写 / 执行的直接 API 与 Agent 工具调用均被禁止；敏感日志与临时文件检查通过。
- 在已确认的部署环境中验证启动、升级、流式响应和报告资源，然后另发新版网页包；不覆盖当前 Windows / Mac 安装包。

参考：[OWASP 会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)、[OWASP SSRF 防护](https://cheatsheetseries.owasp.org/cheatsheets/Server_Side_Request_Forgery_Prevention_Cheat_Sheet.html)。
